# sandbox

Ferramentas e utilitários pessoais, **uma ferramenta por pasta**. Cada pasta tem o código e um README explicando o uso e a instalação.

## Ferramentas

| pasta                  | o que faz                                                                  | ambiente         |
|------------------------|----------------------------------------------------------------------------|------------------|
| [killall](./killall/)  | mata todos os processos com um nome (`killall node`), relatando só falhas | Git Bash/Windows |

## Restaurar tudo depois de formatar

```bash
git clone https://github.com/gugacoder/sandbox.git /d/sources/gugacode/sandbox
```

Depois, siga a seção **Instalação** do README de cada pasta.
